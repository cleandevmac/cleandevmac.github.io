# CleanDevMac website

This repository contains the static landing page for CleanDevMac, published via GitHub Pages.

## Overview

The site presents the CleanDevMac project to visitors, including:

- what the tool does
- how it helps reclaim disk space on macOS
- how to install and run the CLI
- links to the main project and release assets

## Files

- [index.html](index.html) — the homepage content, layout, and styling
- [og.png](og.png) — social preview image used when the site is shared
